## Install the first download in Claude
Each license is issued to one named user (License ID `TIF-VCS-YYYY-NNNN`) and gives access to the private repo.
Licensed to use, not to distribute. Then, in Claude:
```
/plugin marketplace add tif-os/viral-clip-system
/plugin install viral-clip-system@tif-os
```
Or download `viral-clip-system.plugin` from the latest release and open it in the Claude desktop app.

*V2 coming: a standalone panel inside Premiere Pro and After Effects, powered by Claude.*
